# HTML PPT Toolkit

当前版本：`0.16.2`。一套用于 HTML PPT 快速接入编辑器、保存源文件和导出 PDF/PPTX 的 Windows 工具。

主窗口“使用说明”旁的“关于”可查看作者躬行者（全网统一昵称：科学老师学AI）、微信二维码及公众号二维码。二维码内嵌于 EXE，离线可查看。

## 三个入口

| 入口 | 作用 | 边界 |
| --- | --- | --- |
| 快速接入编辑器 | 保留原文件，生成 Lite 可编辑 HTML | 可编辑与另存 HTML；无源文件写回、PDF/PPTX；只做规则自动识别 |
| 打开课件 · 保存与导出 | 打开已经接入编辑器的 Lite/Full 课件，启用 Full 后台服务 | 保存源文件前自动备份；不重复安装工具栏，不负责重构页面 |
| 获取 Skill | 打开 html-ppt-author 的 GitHub 页面及安装说明 | 需要按平台说明安装，不会自动完成安装 |

## 选择流程

- 想快速试用旧网页：先用第一项。自动接入不等于全部内容都已验证可编辑。
- 新建 PPT 或复杂旧网页：用 Skill + Agent 制作/适配结构并验收，再进入工具箱。
- 只改字、换图、排版且另存新版：直接双击 Lite HTML，使用导出 HTML。
- 要保存到源 HTML 或导出 PDF/PPTX：用第二项打开已有 Lite/Full 文件，保持后台窗口运行。
- 第二项发现未接入共享编辑器时，会提示先用第一项或 Skill，不再临时给普通 HTML 注入工具栏。

移动课件时，要携带 HTML、同级 html-ppt-editor 文件夹及实际使用的素材。第一项不修改原文件，生成“原名_通用编辑版.html”；重名时询问覆盖。

## 保存与导出规则

第二项对 Lite 课件启用 Full 配置，保持同一套编辑器；不会新增第二套 SDK 或工具栏。仅打开不会修改源文件。点击保存到源 HTML 后才写回修改，并保存 Full 配置，覆盖前生成 .bak-时间戳 备份。直接双击 Full HTML 仍无法使用源文件写回和 Office 导出，需要工作台后台。

Full 增加服务能力，不会修复图片里的文字、Canvas、复杂 SVG、特殊 iframe 或翻页结构。PDF 为静态页面；可编辑 PPTX 尽量保留文字与基本形状，复杂效果可能栅格化，网页动画不会成为 PowerPoint 动画。原有 Lite 的页面管理、图片和图形工具仍保留。

点击 PDF/PPTX 后会立即显示导出状态和已等待秒数，生成期间同时禁用 Office 导出按钮，避免重复下载。成功后提示查看浏览器下载列表；失败时显示原因并恢复按钮，可重试。工作台会在本次打开时刷新已识别的共享编辑器运行时，以便旧课件也获得更新；仅打开不会写入源文件。

## Windows 导出完整版

正式发布包位于 [GitHub Releases](https://github.com/SevenDamon/HTML-PPT-Toolkit/releases)。请按版本下载 Windows x64 Full ZIP，而非 Source code ZIP。新版若尚未发布，请使用本地交付的同版本完整包。

完整包包含 Node.js、转换引擎、依赖及导出专用浏览器，无需安装 Codex、Skill 或 PowerShell 7。完整解压后打开 EXE，不要只复制 EXE。源码仓库不包含这些大体积运行时依赖，需要自行配置 Node.js 22+ 与兼容引擎。

启动器优先使用 PATH 中的 PowerShell 7，其次 Windows 自带 PowerShell。PS1 使用 UTF-8 BOM 兼容 Windows PowerShell 5.1。CMD 为旧入口兼容保留，接入编辑器 CMD 现在生成 Lite。

## Skill 与开发维护

[获取 html-ppt-author](https://github.com/SevenDamon/codexskill/tree/main/html-ppt-author)。同一 Skill 支持新建与旧 HTML 适配；配合 Agent 和视觉设计工具，验证文字、图片、模块、翻页与导出，不把“出现工具栏”视为适配完成。

唯一维护源是本仓库。编辑器在 editor/，Skill 文档在 skill/；skill-package/html-ppt-author 及已安装 Skill 为生成结果。运行 `node scripts/build-skill.mjs --install` 重建并同步。`构建并同步Skill.cmd` 仅供开发维护，已移出主界面，也不再重编正在运行的 EXE。修改启动器后单独运行 scripts/build-launcher.ps1。

`node scripts/build-portable.mjs <新输出目录>` 构建完整分发目录。DASHI_PPT_PROJECT 指定引擎来源，NODE_LICENSE_FILE 可指定本地 Node 许可证，PORTABLE_BROWSER_DIR 可复用已下载的导出浏览器，否则构建时下载。

## 开发与验证

```powershell
npm run build-skill
node scripts/check-deck.mjs examples/demo.html --profile lite
npm run studio -- --file examples/demo.html
```

工作台启动后，把控制台输出的本地页面 URL 传给浏览器测试脚本：

```powershell
node scripts/smoke-test.mjs "http://127.0.0.1:5537/examples/demo.html"
node scripts/test-selective-text-color.mjs "http://127.0.0.1:5537/examples/demo.html"
node scripts/test-shape-library.mjs "http://127.0.0.1:5537/examples/demo.html"
node scripts/test-text-selection-border-move.mjs "http://127.0.0.1:5537/examples/demo.html"
```

`smoke-test-iframe.mjs` 需要传入一个实际的 iframe 模板课件 URL，不应对标准示例页运行。

修改编辑器核心后运行 `npm run sync-skill`，会从 `skill/` 重建 `skill-package/html-ppt-author/`，并同步到本机 Codex Skills 目录。生成包不应手工维护。

## 能力边界

- HTML 导出保留网页版本中的编辑能力和网页动效。
- PDF 是静态页面快照，不包含动效。
- PPTX 会尽量把文字与基础形状转换为 PowerPoint 可编辑对象；复杂 CSS、蒙版、滤镜、图表和特殊视觉可能栅格化或降级。
- HTML 动效不会自动转换为 PowerPoint 动画。两套动画引擎的数据模型不同，强行等价转换会产生不稳定结果。
- 直接用 `file://` 打开时，浏览器安全限制下只能导出 HTML；保存源文件、PDF、PPTX 需要通过本地工作台打开。

## iframe 模板课件

工具现已识别“外层网页 + `iframe srcdoc` + 多个 `template.page-data`”的课件格式，例如飞象老师导出的互动课件。转换脚本会自动安装 iframe 适配器：

- 工具栏显示在当前真正的课件页面内；
- 切换页面后自动重新挂载；
- 修改以页面状态保存在完整外层 HTML 中；
- “切换专注显示”只做可恢复的临时隐藏；“点选删除页面元素”会在保存源 HTML 或导出 HTML 时永久移除所选可见 DOM 节点，并可用“撤回上次页面删除”在保存前恢复；课件主体、承载 iframe、脚本和元数据默认受保护；
- PDF 使用视觉截图导出；
- `PPT` 导出可编辑版：把 iframe 页面展开后，将文字和基础形状转换为 PowerPoint 对象；
- `IMG` 导出保真版：每页作为整页图片，视觉更稳，但内容不可逐项编辑。

可编辑版的文字和基础形状可以在 PowerPoint 中修改，但复杂蒙版、渐变、滤镜、交互组件和部分图片效果仍可能栅格化；网页动效也不会变成 PowerPoint 动画。需要完全保真时使用 `IMG`，需要继续改字和改基础形状时使用 `PPT`。隐藏或删除第三方品牌标识前，应确认你对课件拥有相应使用和修改权限。

## 空白页与图片效果（0.10.0）

0.13.0：工具栏、页面管理和图片编辑栏统一为浅色面板、石墨文字与青绿色强调，使用共享字体、控件和主题变量。页面管理左侧为固定设置区，右侧缩略图独立滚动；可拖动标题栏移动窗口，拖右下角缩放，通过“复位窗口”恢复默认大小与位置。缩略图随窗口尺寸自适应。较矮窗口下左侧设置可单独滚动，不跟随右侧滚动。安装器支持升级内嵌共享编辑器的旧 HTML，避免旧脚本和旧样式并存。

0.12.0：页面管理的“本地背景图”可选择本机图片，内嵌为 Data URL；支持“填满画布（可能裁边）”“完整显示（可能留边）”、移除背景和撤回。根据选中页显示画布比例与尺寸建议；16:9 推荐 1920 × 1080，高清可用 3840 × 2160。背景随 HTML 保存/导出，不依赖原图片路径。

图片下的说明文字现在可编辑，旁边“放大”等操作继续保留。共享核心针对 `.evidence-image > span`、`figure > figcaption`、`[data-ppt-caption]` 自动识别直接文字；不会全局解锁受保护的页码或导航。自定义模板可显式标记 `data-ppt-caption`。

0.11.0 起，选中图片会自动显示可拖动的横向图片编辑栏，优先放在图片附近的空余位置；点击关闭后仍可通过 `◐` 按钮重新打开。提供左右旋转 90°、水平/垂直翻转及角度输入。圆角、渐变范围和不透明度采用实时滑条与数值框双向同步，渐变方向以预览图示点选。拖一次滑条记作一步撤回，浮动栏会限制在浏览器窗口内；编辑栏本身不会被保存到课件画面或导出文件中。

页面管理中点击“＋ 空白页”，会在选中页后插入一张空白页，继承该页的背景颜色、背景图/渐变与画布尺寸。空白页不包含原页面的文字、图片或装饰元素。使用“背景”颜色框可为选中页设置纯色背景（替换背景图/渐变），再双击页面卡片进入，使用工具栏添加文字、图片和图形。

选择图片后，点击图片组的 `◐ 图片效果`，可以调整旋转角度、圆角、形状蒙版、渐变透明方向和范围，以及整体不透明度。支持圆形/椭圆、三角形、菱形、五边形、六边形、五角星。蒙版与渐变可叠加，效果可撤回，也可恢复原始效果。旋转后需恢复 0° 才能使用矩形裁剪；形状蒙版会替换矩形裁剪。该面板用于 `<img>` 图片，背景图应先作为图片添加后使用这些效果。

Lite 与 Full 均可使用；保存/导出 HTML 后保留效果。复杂蒙版和透明效果在可编辑 PPTX 中可能栅格化或降级，不能保证仍为 PowerPoint 原生图片效果。

## 复制元素与模块（0.15.0）

编辑组新增“复制元素及样式”和“粘贴元素”。选中文字框、图片或图形后，可连同样式复制；开启“选择整个模块”后复制整张卡片，关闭后可单独复制卡片中的小色块或文字框。支持多选复制，以及在当前课件的其他页粘贴；副本略微错开位置，不挤动原页面布局。

- `Ctrl+C / Ctrl+V`：复制、粘贴选中的元素；正在框选文字时仍使用普通文字复制。
- `Ctrl+D`：直接复制出一个副本。macOS 使用 Cmd。
- 副本可独立编辑、移动、删除和设置动画；撤回/重做及导出 HTML 后重新打开均保留。复制的同步动画组与原组相互独立。

复制范围是当前打开的课件。采用 DOM 和计算样式保留外观，第三方脚本的独立事件绑定、Canvas 绘图和复杂组件不保证能完整复制。

## 模块选择与同时出现（0.9.0）

0.14.0：模块识别支持没有底色和边框的重复流程节点（例如“编号＋标题＋说明”）。开启“选择模块”后，点击节点内任一文字可选完整节点；不能识别的自定义结构可以使用 `data-ppt-module` 明确标记。普通文字可以作为模块模式下的后备选择，不会因此选中整张幻灯片。

支持 `Ctrl + 鼠标左键` 临时多选（macOS 可用 Cmd），无需先开启多选开关。开启模块选择时多选整组模块，关闭时多选单个文字/图片/图形；再次 Ctrl 点击取消该项，普通点击回到单选。原来的多选按钮仍可使用。

- 编辑组的 `▣`“选择整个模块”：点击卡片内文字或空白选择外层卡片，拖青色边框移动整个模块，使用动画按钮设置整块按键出现。再次点击退出模块选择后可继续编辑内部文字。
- `☑`“多选元素”：依次点击选中/取消，配合模块选择可多选卡片，关闭模块选择后还可以加入独立文字、图片。只支持当前页，父子节点不会重复加入。
- 动画组 `⇉`“同时出现”：将选中元素设为同一次按键触发。它们保持各自的位置与可编辑性，调整先后顺序时整组一起移动。
- `≋`“拆为逐项出现”：拆开同步组；撤回/重做、浏览器草稿和 HTML 导出保留同步关系。

同步出现通过 `data-hppt-reveal-group` 保存。共享编辑器接管当前页的分组前进/后退按键，以及 `data-action="next/prev"` 按钮；其他自定义点击或自动播放入口需宿主按组处理。此动画用于 HTML 演示，PDF 为静态输出，PPTX 不保留网页动画。

## 页面管理（0.8.0）

编辑模式点击“页面”组的 `▦`，可查看页面缩略图，拖动排序、前移/后移、移动到指定页、复制和删除页面。双击卡片跳到该页。操作接入撤回/重做，至少保留一页；保存源 HTML 或导出 HTML 后保留新顺序。复制页使用独立页面和编辑标识。Lite 与 Full 均提供此功能。

目前支持同一容器内的标准幻灯片及 Wise PPT 轨道页。iframe 模板课件仍由外层控制器管理，点击时会提示暂不支持。自定义页码、目录、点击导航、弹窗和页面数组需要宿主接入 `hppt:pages-changed` 事件或提供相应适配；不能保证任意第三方脚本都能自动同步。常见受保护页脚数字、进度、`#counter`、`#toc-grid` 和 `data-action` 导航已提供适配。网页动效不会转换为 PPTX 动画。

## Wise PPT 兼容

工具会识别 `data-runtime="wise-ppt-deck"` 和 `#track > .slide` 结构，并自动完成以下适配：

- 工具栏图标使用 `data-hppt-icon` 私有属性，不与宿主页面的 `data-icon` 图标系统冲突；
- 将 `WisePPTRuntime.go()` 桥接到统一的 `window.go()` 接口；
- 暴露稳定的逐页发现接口；
- 导出时把横向轨道临时规范化为转换器可识别的直接幻灯片结构，不改写源 HTML 的视觉结构。

PDF 和保真图片版 PPTX 会按页面截图输出。可编辑 PPTX 会尽量保留文字和基础图形；复杂 SVG、滤镜和自定义组件可能栅格化。

0.14.1 会持续补充识别遗漏文字，即使页面已经有部分编辑标记。页眉栏目名、课程名、内容按钮文案和来源说明可以自动改字；受保护区域仍禁止删除、拖动和动画。页码、进度条、导航操作及工具栏保持锁定；自定义不可编辑区域可加 `data-ppt-text-locked`。混排文案只补充文字片段，保留旁边的操作控件。重新安装编辑器时，如果页面带有 `#editor-bundle` 便携包，安装器会同步更新其中的共享编辑器版本，避免导出的单文件 HTML 回退到旧逻辑。
